# retail-operations-analytics dashboard
Retail analytics project with Excel, Power BI and MySQL to investigate waste, sales, staff and peak hours!

AIM

The aim of this project was to find insightful data out of normal retail numbers that help with decision-making.

Tools Used:
- Excel
- Power BI
- MySQL
- SQL

Questions
- These are the questions I asked myself while exploring this project:
- Which days generate the most revenue?
- Which product categories perform best?
- Are high-revenue categories driven by price or sales volume?
- Which categories generate the most waste?
- When are checkout waits longest?
- Which hours have the highest transaction volumes?
- Does staffing appear to explain checkout waiting times?

Summaries
### Saturday generated the highest revenue

### Frozen generated the highest category revenue

However, drinks sold the most units, frozen generated the most revenue indicating frozen food have a higher selling price.

### Fresh Produce generated the most waste

This makes sense due to stock rotation and storing conditions.
